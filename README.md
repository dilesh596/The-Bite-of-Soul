# The Bite of Soul

A soulful, premium restaurant landing website crafted as a multi-page static experience for a modern food brand.

## Overview

The Bite of Soul is a visually rich restaurant website designed to highlight signature dishes, curated beverages, desserts, and the overall brand story of a warm and refined dining experience. The project includes multiple standalone HTML pages that work together to create an elegant, easy-to-navigate digital storefront.

## Featured Pages

- Home: `Website.html`
- About: `about.html`
- Menu: `menu.html`
- Veg: `veg.html`
- Non-Veg: `non-veg.html`
- Drinks: `drinks.html`
- Desserts: `desserts.html`
- CEO: `ceo.html`
- Links: `link.html`

## Highlights

- Elegant restaurant branding and premium visual identity
- Multi-page static website layout
- Dedicated sections for vegetarian, non-vegetarian, drinks, and desserts

## Run Locally

1. Clone the repository.
2. Open `Website.html` in your browser, or run a local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/Website.html
```

## Deployment

This project is well suited for GitHub Pages or any static site hosting service. Since it is a static HTML site, deployment is simple and lightweight.
